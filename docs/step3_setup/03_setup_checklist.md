# 3단계 산출물: 초기 셋업 체크리스트

## 1. 프로젝트 생성
- Next.js 프로젝트 생성
- TypeScript 설정
- ESLint / Prettier 설정

## 2. 인증 및 DB 연결
- Vercel Marketplace에서 Neon Postgres 생성 및 프로젝트 연결
- Auth 설정
- DB 연결 테스트
- 환경 변수 설정

## 3. 공통 레이아웃 구성
- 사이드바 구성
- 상단 헤더 구성
- 모바일 메뉴 구성
- 반응형 레이아웃 적용

## 4. 디자인 시스템 구성
- 색상 토큰 설정
- 버튼/카드/테이블/폼 컴포넌트 구성
- 공통 폰트 및 spacing 정의

## 5. PWA 기본 설정
- manifest 작성
- service worker 설정
- 아이콘 등록
- 오프라인 기본 화면 구성

## 6. 개발 완료 기준
- 로그인 화면이 동작한다.
- 대시보드 진입이 가능하다.
- 공통 레이아웃이 반응형으로 보인다.
- Neon Postgres와 연결된 기본 화면이 표시된다.
