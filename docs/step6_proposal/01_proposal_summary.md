# 6단계 산출물: 제안 요약서

## 1. 제안 개요
본 제안은 공개 홈페이지 리뉴얼과 사내 인트라넷 통합 구축을 단계적으로 진행하기 위한 개발 계획서이다.

## 2. 핵심 목표
- 사내 인트라넷의 핵심 업무 흐름을 실제 운영 가능한 형태로 구현한다.
- 모바일, 태블릿, 데스크톱에서 모두 사용 가능하도록 반응형으로 설계한다.
- 다양한 OS에서 접근 가능하도록 웹 기반으로 구현하고, 앱 확장까지 준비한다.
- 보안과 권한 관리 체계를 사전에 설계한다.

## 3. 추진 방향
1. MVP 중심으로 우선 구현한다.
2. 인증, 대시보드, 타임시트, 근태, 결재, 게시판을 순차적으로 개발한다.
3. 반응형 UI와 PWA 기반 확장 구조를 적용한다.
4. 운영 배포 전 테스트와 보안 검수를 진행한다.

## 4. 기대 효과
- 사내 업무 효율 향상
- 근태 및 결재 처리 자동화
- PM 및 관리자 운영 편의성 향상
- 향후 앱 확장 기반 확보
