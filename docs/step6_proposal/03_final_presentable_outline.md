# 6단계 산출물: 발표용 구성안

## 1. 제목
사내 인트라넷 통합 구축 개발 계획 및 실행 전략

## 2. 발표 흐름
1. 프로젝트 배경
2. 해결하고자 하는 문제
3. 제안 방향
4. 개발 범위
5. 개발 일정
6. 기대 효과
7. 결론

## 3. 발표 포인트
- 모바일/태블릿/PC 지원
- 다양한 OS 대응 가능
- PWA 및 앱 확장 가능성
- 보안과 권한 기반 구조
- MVP 우선 개발 후 단계적 확장

## 4. 마무리 문구
본 프로젝트는 단순한 홈페이지 리뉴얼이 아니라, 내부 업무 효율을 높이는 통합 디지털 운영 플랫폼으로 발전할 수 있는 기반을 마련하는 프로젝트입니다.
