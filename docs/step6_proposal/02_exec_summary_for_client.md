# 6단계 산출물: 고객사용 실행 요약안

## 1. 프로젝트 방향
본 프로젝트는 홈페이지 리뉴얼과 사내 인트라넷 통합 구축을 하나의 흐름으로 연결하여, 웹 기반으로 먼저 구축한 뒤 앱 확장까지 이어지는 방식으로 진행하는 것이 적합하다.

## 2. 개발 전략
- 웹 앱 우선 개발
- 반응형 UI 적용
- PWA 기반 설치형 경험 제공
- 모바일 앱 확장 가능 구조 확보

## 3. 개발 범위
- 인증 및 권한 관리
- 대시보드
- 타임시트
- 근태 관리
- 전자결재
- 사내 게시판
- 관리자 기능

## 4. 기대 결과
- 업무 효율 개선
- 운영 투명성 향상
- 내부 시스템 통합 관리 가능
- 향후 확장성 확보
