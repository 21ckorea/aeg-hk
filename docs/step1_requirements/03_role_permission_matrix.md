# 1단계 산출물: 권한 매트릭스

## 1. 권한 구분
| 역할 | 주요 기능 | 접근 범위 |
|---|---|---|
| 일반 사원 | 로그인, 대시보드, 타임시트 입력, 근태 기록, 결재 기안, 게시판 이용 | 본인 데이터 및 지정된 프로젝트 정보 |
| PM | 사원 기능 + 프로젝트 관리 + 타임시트 승인 | 소속 프로젝트 및 하위 인력 정보 |
| 관리자 | 사원/부서/직급/권한 관리, 프로젝트 관리, 공지사항 관리 | 전사 운영 데이터 |
| 시스템 관리자 | 전체 설정 관리, 시스템 운영, 권한 최상위 관리 | 전체 시스템 |

## 2. 메뉴 접근 기준
- 일반 사원: 대시보드, 타임시트, 근태, 결재, 게시판
- PM: 위 항목 + 프로젝트 기준 승인/조회
- 관리자: 위 항목 + 사원/프로젝트/권한 관리
- 시스템 관리자: 전체 관리자 기능 및 시스템 설정

## 3. 보안 원칙
- 권한 없는 메뉴는 노출하지 않는다.
- 데이터 조회는 본인 또는 승인된 범위만 가능해야 한다.
- 관리자 기능은 관리자 권한이 있는 사용자만 접근 가능해야 한다.
