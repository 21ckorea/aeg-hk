# 1단계 산출물: 사용자 흐름도

## 1. 로그인 흐름
1. 사용자 접속
2. SSO 로그인 시도
3. 화이트리스트 확인
4. 권한에 따라 대시보드 진입
5. 로그인 실패 시 접근 제한 화면 표시

## 2. 대시보드 흐름
1. 로그인 후 대시보드 진입
2. 개인 근태 상태 확인
3. 결재 대기 건수 확인
4. 공지사항 확인
5. 주요 메뉴로 이동

## 3. 타임시트 흐름
1. 사용자가 타임시트 메뉴 진입
2. 월별 입력 화면 확인
3. 날짜/프로젝트 기준으로 시간 입력
4. 입력값 검증
5. 저장 또는 마감
6. PM 승인 대기 상태로 전환

## 4. 근태 흐름
1. 사용자가 근태 메뉴 진입
2. 출근/퇴근 버튼 선택
3. 기록 저장
4. 월간 근태 기록 조회
5. 지각/연차/조퇴 상태 확인

## 5. 전자결재 흐름
1. 결재 메뉴 진입
2. 기안서 작성
3. 결재선 지정
4. 상신
5. 승인/반려/회수 상태 변경
6. 결재 이력 확인

## 6. 관리자 흐름
1. 관리자 로그인
2. 사원 관리 메뉴 진입
3. 사원 등록/수정
4. 프로젝트 관리 메뉴 진입
5. 프로젝트 생성/수정/상태 변경
6. 권한 관리 수행
