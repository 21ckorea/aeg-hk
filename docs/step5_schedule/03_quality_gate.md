# 5단계 산출물: 품질 검수 기준

## 1. 기능 검수
- 로그인 및 권한 분기가 정상 동작한다.
- 대시보드, 타임시트, 근태, 결재, 게시판이 정상 동작한다.
- 관리자 기능이 권한에 따라 분기된다.

## 2. UI 검수
- PC, 태블릿, 모바일에서 레이아웃이 정상 동작한다.
- 버튼과 폼이 터치 환경에서도 사용 가능하다.

## 3. 보안 검수
- 권한 없는 접근이 차단된다.
- 민감 정보가 노출되지 않는다.
- 로그인 세션이 안전하게 관리된다.

## 4. 운영 검수
- 배포 후 기본 페이지 접근이 가능하다.
- 오류 로그가 수집된다.
- PWA 설치 기준이 만족된다.
