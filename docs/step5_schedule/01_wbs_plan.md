# 5단계 산출물: WBS 일정안

## 1. 1주차
- 요구사항 정리
- 화면 흐름 정리
- 권한 구조 정의

## 2. 2주차
- 화면 설계 완료
- DB 스키마 초안 작성
- 공통 레이아웃 기본 구성

## 3. 3주차
- 인증 모듈 구현
- 권한 분기 구현
- 로그인/로그아웃 테스트

## 4. 4주차
- 대시보드 구현
- 공지사항 요약 표시
- 기본 메뉴 구성

## 5. 5주차

- 저장/마감 로직 구현

## 6. 6주차
- 근태 기능 구현
- 기록 조회 화면 구현

## 7. 7주차

- 승인/반려 흐름 구현

## 8. 8주차

- 댓글 기능 구현

## 9. 9주차

## 10. 10주차

## 11. 11주차
