# Demo Readout Notes

## What is ready now
- Public homepage + intranet shell
- Dashboard, timesheet, manpower, approval, attendance, and diary workflows
- Mock role simulation for manager/staff/admin perspectives
- PWA manifest and service worker registration

## Suggested demo flow
1. Open the public homepage.
2. Switch into the intranet view.
3. Toggle role simulation to show different permissions and UI context.
4. Move through the dashboard, timesheet, approval, and attendance modules.
5. Highlight the architecture path toward real backend integration.
