# 사내 인트라넷 통합 구축 개발 계획서

## 1. 프로젝트 목표

본 프로젝트는 공개 홈페이지 리뉴얼과 사내 인트라넷 통합 구축을 단계적으로 진행하기 위한 초기 구축 로드맵이다. 우선순위는 다음과 같다.

1. 사내 인트라넷의 핵심 업무 흐름을 실제로 운영 가능한 형태로 구현한다.
2. 모바일, 태블릿, 데스크톱 환경에서 동일한 경험을 제공하도록 반응형 구조로 설계한다.
3. 다양한 OS에서 접근 가능하도록 웹 기반으로 구현하되, 앱 출시까지 확장 가능하게 만든다.
4. 보안·권한·로그 관리까지 포함한 실제 운영 환경에 가까운 구조로 만든다.

---

## 2. 개발 원칙

### 2.1. 사용자 중심 설계
- PC/태블릿/모바일에서 모두 자연스럽게 사용 가능해야 한다.
- 터치 기반 UI와 데스크톱 기반 UI가 서로 충돌하지 않도록 설계한다.
- 핵심 기능은 3클릭 이내로 접근 가능해야 한다.

### 2.2. 크로스 플랫폼 전략
- 기본 플랫폼은 웹 앱(Web App)으로 구축한다.
- 웹 앱은 PWA(Progressive Web App) 형태로 제공하여 모바일 홈 화면 설치가 가능하게 한다.
- 이후에는 Capacitor 또는 Tauri 기반으로 iOS/Android/Windows/macOS 앱으로 확장할 수 있게 구조를 설계한다.

### 2.3. 보안 우선 설계
- 로그인은 SSO 기반으로 구성한다.
- 내부 계정은 화이트리스트 기반 접근 제어를 적용한다.
- 데이터는 DB 레벨 권한 제어(RLS 등)를 적용한다.
- 민감 데이터는 암호화 저장 및 접근 로그를 남긴다.

### 4.2. 백엔드/데이터베이스

- PWA 지원
- Sentry (에러 추적)

- 백엔드 API: 인증, 권한, 데이터 처리
- 데이터베이스: 사원, 프로젝트, 결재, 근태, 게시판 데이터 저장

- 시스템 관리자

각 권한별 접근 가능한 메뉴와 기능이 분리되어야 한다.

## 13. 추천 실행 흐름으로 바로 진행하는 체크리스트

아래 순서대로 진행하면, 실제 개발 시작 시점에서 혼선 없이 바로 작업을 이어갈 수 있다.

### 1단계: 요구사항 정리 및 사용자 흐름 확정
- 사내 인트라넷에서 가장 먼저 필요한 기능 5가지를 선정한다.
- 근태, 타임시트, 전자결재, 게시판, 관리자 메뉴의 핵심 흐름을 그림으로 정리한다.
- 권한별 메뉴 접근 범위를 정의한다.
- 산출물: 요구사항 정의서, 화면 흐름도, 권한 매트릭스

### 2단계: 화면 설계와 데이터 구조 정의
- 로그인, 대시보드, 타임시트, 결재, 게시판, 관리자 화면의 와이어프레임을 만든다.
- 사용자 테이블, 프로젝트 테이블, 근태 테이블, 결재 테이블, 게시판 테이블의 기본 스키마를 설계한다.
- 산출물: 화면 설계서, ERD, 기본 DB 스키마

### 3단계: 기본 개발 환경 구성
- Next.js + TypeScript 프로젝트를 생성한다.
- Supabase Auth, DB, Storage를 연결한다.
- 공통 레이아웃, 사이드바, 상단바, 모바일 메뉴를 구성한다.
- 산출물: 로그인 가능한 기본 웹 앱

### 4단계: 인증 및 권한 구조 구현
- SSO 로그인 연동을 구현한다.
- 사원/부서/직급/권한 테이블을 연결한다.
- 일반 사원, PM, 관리자 권한에 따라 메뉴 접근을 분기한다.
- 산출물: 로그인, 세션 유지, 권한 기반 화면 제어

### 5단계: 핵심 업무 모듈 먼저 구현
- 대시보드 화면을 만든다.
- 타임시트 입력 기능을 구현한다.
- 근태 체크인/체크아웃 기능을 넣는다.
- 전자결재 기안/결재 상태 흐름을 구현한다.
- 사내 게시판 기본 CRUD를 구현한다.
- 산출물: MVP 기능이 동작하는 인트라넷 웹앱

### 6단계: 관리자 기능 및 운영 기능 추가
- 사원 등록/수정/상태 변경 기능을 구현한다.
- 프로젝트 등록 및 상태 관리 기능을 넣는다.
- 공지사항 관리와 권한별 접근 제어를 강화한다.
- 산출물: 실제 운영자가 관리 가능한 관리자 페이지

### 7단계: 반응형 및 크로스 플랫폼 정리
- PC, 태블릿, 모바일 화면 배치를 검증한다.
- PWA 설정을 완료하고 설치 가능한 형태로 만든다.
- 모바일 앱 확장을 위해 Capacitor 연동 준비를 한다.
- 산출물: 반응형 웹 앱 + PWA 기반 설치형 UX

### 8단계: 테스트, 보안, 배포
- 권한 우회, 입력 검증, 결재 상태 전이, 타임시트 제한 로직을 테스트한다.
- 보안 점검과 백업/복구 흐름을 확인한다.
- 운영 서버에 배포하고 모니터링을 연결한다.
- 산출물: 안정화된 운영 배포본

## 14. 한 줄 결론

사내 인트라넷은 “웹 기반으로 먼저 만들고, 그 위에 PWA와 앱 확장을 붙이는” 방식이 가장 효율적이며, 모바일/태블릿/다양한 OS 지원과 보안까지 동시에 반영할 수 있는 구조로 진행하는 것이 가장 적합하다.
