# 실제 발표용 슬라이드 문구(1장씩)

## 슬라이드 1. 프로젝트 제목
홈페이지 리뉴얼 및 사내 인트라넷 통합 구축

## 슬라이드 2. 제안 배경
홈페이지와 사내 업무 시스템이 분리되어 있어, 정보 접근성과 업무 효율성 향상이 필요합니다.

## 슬라이드 3. 제안 목표
외부 브랜드 경험과 내부 운영 효율을 동시에 강화하는 디지털 플랫폼을 구축합니다.

## 슬라이드 4. 핵심 솔루션
반응형 웹 기반 서비스, SSO 인증, 권한 기반 보안 구조, 모바일/태블릿/PC 대응.

## 슬라이드 5. 주요 기능
대시보드, 타임시트, 근태 관리, 전자결재, 사내 게시판, 관리자 기능.

## 슬라이드 6. 개발 전략
MVP 우선 구현, 웹 앱 우선 개발, PWA와 앱 확장까지 고려한 단계적 구축.

## 슬라이드 7. 기대 효과
업무 효율 향상, 운영 투명성 강화, 향후 서비스 확장성 확보.

## 슬라이드 8. 결론
회사 차원의 디지털 전환을 위한 실용적이고 확장 가능한 기반을 마련합니다.
