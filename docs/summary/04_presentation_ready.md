# 발표용 문장 다듬은 버전

## 1. 프로젝트 소개
그룹환경종합건축사사무소의 홈페이지 리뉴얼과 사내 인트라넷 통합 구축은, 외부 홍보와 내부 운영을 하나의 디지털 플랫폼으로 연결하는 핵심 전환 프로젝트입니다.

## 2. 제안 배경
기존의 홈페이지와 사내 업무 시스템이 분리되어 있어, 정보 접근성과 업무 효율성이 낮아질 수 있는 상황입니다. 이를 해결하기 위해, 사용자 경험을 고려한 웹 기반 통합 플랫폼을 구축하고자 합니다.

## 3. 핵심 목표
- 모바일, 태블릿, PC 환경에서 모두 안정적으로 이용 가능한 반응형 서비스 구축
- 다양한 OS와 브라우저 환경에서 접근 가능한 크로스 플랫폼 구조 설계
- SSO 기반 인증과 권한 관리 체계를 통해 보안성과 운영 효율 확보
- MVP 우선 개발 후, 단계적으로 앱 확장과 고도화가 가능한 기반 마련

## 4. 제공 범위
- 공개 홈페이지 리뉴얼
- 사내 인트라넷 핵심 업무 기능 구현
- 대시보드, 타임시트, 근태, 전자결재, 게시판, 관리자 기능 제공
- 반응형 UX와 PWA 기반 확장 구조 적용

## 5. 기대 효과
이 프로젝트를 통해 사내 업무 효율은 향상되고, 내부 운영의 투명성과 관리 편의성도 크게 개선될 수 있습니다. 또한 향후 모바일 앱 및 추가 서비스 확장까지 자연스럽게 이어질 수 있는 기반을 마련할 수 있습니다.

## 6. 결론
본 제안은 단순한 홈페이지 리뉴얼이 아니라, 회사의 외부 브랜드 경험과 내부 운영 효율을 동시에 강화하는 통합 디지털 플랫폼 구축안입니다.
