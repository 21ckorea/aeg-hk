# 바로 보기 좋은 마크다운 정리본

## 프로젝트 한 줄 요약
공개 홈페이지 리뉴얼과 사내 인트라넷 통합 구축을 웹 기반으로 먼저 구현하고, 이후 PWA와 앱 확장까지 이어질 수 있는 구조로 설계하는 프로젝트입니다.

## 핵심 포인트
- 반응형 대응: PC, 태블릿, 모바일 지원
- 크로스 플랫폼: 다양한 OS에서 접근 가능
- 앱 확장성: PWA 및 모바일 앱 확장 가능
- 보안 중심: SSO, 권한 관리, 접근 제어
- 단계적 개발: MVP 우선 → 운영 안정화 → 확장

## 구현 범위
1. 인증 및 권한 관리
2. 대시보드
3. 타임시트
4. 근태 관리
5. 전자결재
6. 사내 게시판
7. 관리자 기능

## 개발 방식
- 웹 앱 우선 개발
- 공통 UI/UX 설계
- Supabase 기반 데이터 관리
- Vercel 기반 배포
- 운영 전 테스트 및 보안 검증

## 기대 효과
- 사내 업무 효율 향상
- 정보 접근성 강화
- 관리자 운영 효율 증가
- 향후 앱 확장 기반 마련
