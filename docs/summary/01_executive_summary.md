# 대표 발표용 1페이지 요약본

## 1. 프로젝트 개요
본 프로젝트는 홈페이지 리뉴얼과 사내 인트라넷 통합 구축을 하나의 디지털 전환 전략으로 구성한 사업이다. 핵심 목표는 내부 업무 효율을 높이고, 모바일·태블릿·PC를 포함한 다양한 환경에서 안정적으로 사용할 수 있는 통합 운영 플랫폼을 구축하는 것이다.

## 2. 추진 방향
- 공개 홈페이지 리뉴얼
- 사내 인트라넷 통합 구축
- 반응형 웹 설계
- 다양한 OS 대응 및 앱 확장 가능 구조 구현
- SSO 기반 인증과 권한 관리 적용

## 3. 주요 기능
- 로그인 및 권한 관리
- 대시보드
- 타임시트 입력 및 마감
- 근태 관리
- 전자결재
- 사내 게시판
- 관리자 기능

## 4. 개발 전략
- MVP 중심으로 우선 구현
- 웹 앱 우선 개발 후 PWA 및 앱 확장 가능 구조로 확장
- 보안, 권한, 운영 안정성까지 설계 단계에서 반영

## 5. 기대 효과
- 내부 업무 효율 향상
- 근태·결재·타임시트 업무 자동화
- 관리자 운영 편의성 강화
- 향후 앱 확장 기반 확보

## 6. 추진 일정
- 1~2주: 요구사항 및 화면 설계
- 3~4주: 인증 및 공통 레이아웃 구축
- 5~8주: 핵심 모듈 개발
- 9~10주: 관리자 기능 및 운영 기능 구현
- 11~12주: 테스트, 보안 점검, 운영 배포
