# 회사명 반영형 최종본

(주)그룹환경종합건축사사무소의 홈페이지 리뉴얼과 사내 인트라넷 통합 구축 제안은, 외부 브랜드 경험과 내부 업무 운영을 함께 강화하기 위한 전략적 디지털 전환 프로젝트입니다.

본 제안은 홈페이지의 정보 전달력과 사용자 경험을 개선하고, 사내 인트라넷을 통해 근태, 타임시트, 전자결재, 게시판, 관리자 운영까지 하나의 통합된 환경으로 구성하는 것을 목표로 합니다.

우리는 웹 기반으로 먼저 구축하고, 반응형 설계와 PWA 확장 구조를 적용하여 PC, 태블릿, 모바일을 포함한 다양한 환경에서 안정적으로 이용 가능한 플랫폼을 구현하고자 합니다. 또한 SSO 기반 인증과 권한 관리 체계를 통해 보안성과 운영 안정성을 확보할 수 있도록 설계합니다.

이 프로젝트는 단순한 홈페이지 리뉴얼이 아니라, 회사의 디지털 경쟁력을 높이고 내부 운영 효율을 강화하는 핵심 인프라 구축으로 이어질 것입니다.
