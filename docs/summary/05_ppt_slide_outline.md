# PPT 슬라이드 8장 구성안

## 1장. 프로젝트 배경
- 홈페이지와 인트라넷이 분리되어 운영되는 현실
- 정보 접근성과 업무 효율성 개선 필요성

## 2장. 제안 목표
- 외부 홍보와 내부 운영을 하나의 통합 플랫폼으로 연결
- 사용자 중심의 디지털 경험 제공

## 3장. 핵심 솔루션
- 반응형 웹 기반 서비스
- SSO 기반 인증과 권한 관리
- 모바일/태블릿/PC 대응

## 4장. 주요 기능
- 대시보드
- 타임시트
- 근태 관리
- 전자결재
- 사내 게시판

## 5장. 개발 전략
- MVP 우선 구현
- 웹 앱 우선 개발
- PWA 및 앱 확장 가능 구조 확보

## 6장. 일정 계획
- 1~2주: 기획 및 설계
- 3~4주: 기반 인프라 구축
- 5~8주: 핵심 모듈 개발
- 9~12주: 테스트, 보안, 운영 배포

## 7장. 기대 효과
- 업무 효율 향상
- 운영 투명성 강화
- 향후 서비스 확장성 확보

## 8장. 결론
- 홈페이지 리뉴얼과 사내 인트라넷 통합은 회사의 디지털 경쟁력을 높이는 중요한 과제입니다.
