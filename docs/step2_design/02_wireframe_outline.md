# 2단계 산출물: 와이어프레임 구성안

## 1. 로그인 화면
- 상단: 로고
- 중앙: 로그인 카드
- 하단: 회사 메일 제한 안내

## 2. 대시보드 화면
- 상단: 환영 메시지
- 좌측: 근태 상태 카드
- 중앙: 결재/공지 요약
- 우측: 프로젝트 요약

## 3. 타임시트 화면
- 상단: 월 선택 및 저장 버튼
- 본문: 날짜 × 프로젝트 그리드
- 하단: 총 시간 요약 및 제한 안내

## 4. 근태 화면
- 상단: 출근/퇴근 버튼
- 중단: 오늘의 근태 상태
- 하단: 월간 기록 테이블

## 5. 전자결재 화면
- 왼쪽: 결재 목록
- 오른쪽: 상세 내용/버튼
- 상단: 기안 작성 버튼

## 6. 게시판 화면
- 상단: 글쓰기 버튼
- 중앙: 목록
- 하단: 페이지네이션

## 7. 관리자 화면
- 좌측 탭: 사원/프로젝트/권한
- 우측 콘텐츠: 리스트 및 등록 폼
