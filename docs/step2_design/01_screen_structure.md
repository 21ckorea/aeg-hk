# 2단계 산출물: 화면 구조 설계

## 1. 공통 레이아웃
- 좌측 사이드바: 메뉴 네비게이션
- 상단 헤더: 사용자 정보, 알림, 로그아웃
- 메인 콘텐츠 영역: 각 기능 화면 표시
- 모바일에서는 상단 햄버거 메뉴로 전환

## 2. 로그인 화면
- 로고/브랜드 영역
- SSO 로그인 버튼
- 회사 메일 제한 안내 문구
- 로그인 실패 시 에러 메시지 표시

## 3. 대시보드 화면
- 개인 근태 상태 카드
- 결재 대기 건수 카드
- 공지사항 요약 리스트
- 오늘의 일정/프로젝트 요약 카드

## 4. 타임시트 화면
- 월별 그리드 형태의 입력 표
- 프로젝트 선택 드롭다운
- 날짜별 시간 입력 필드
- 저장/마감 버튼
- 입력 제한 안내 메시지

## 5. 근태 화면
- 출근/퇴근 버튼
- 오늘 근태 상태 표시
- 월간 근태 목록 테이블
- 연차/지각/조퇴 상태 배지

## 6. 전자결재 화면
- 결재 목록 화면
- 기안 작성 화면
- 결재 상세 화면
- 승인/반려 버튼

## 7. 게시판 화면
- 공지사항 목록
- 자유게시판 목록
- 글 작성/댓글 기능
- 관리자 전용 공지 작성 버튼

## 8. 관리자 화면
- 사원 관리 목록
- 프로젝트 관리 목록
- 권한 관리 탭
- 부서/직급 관리 섹션
