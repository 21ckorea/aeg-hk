# 4단계 산출물: 모듈별 개발 계획

## 1. 인증 모듈
- SSO 로그인 연결
- 화이트리스트 검증
- 세션 유지 및 로그아웃
- 완료 기준: 로그인 후 권한별 메뉴가 다르게 보인다.

## 2. 대시보드 모듈
- 개인 근태 상태 표시
- 결재 대기 건수 표시
- 공지사항 요약 표시
- 완료 기준: 로그인 후 대시보드에서 핵심 정보를 확인할 수 있다.

## 3. 타임시트 모듈
- 월별 입력 그리드
- 프로젝트별 시간 입력
- 입력값 검증
- 마감 기능
- 완료 기준: 시간 입력 및 저장이 가능하고 제한 로직이 동작한다.

## 4. 근태 모듈
- 출근/퇴근 기록
- 월간 기록 조회
- 상태 배지 표시
- 완료 기준: 출퇴근 기록이 저장되고 조회된다.

## 5. 전자결재 모듈
- 기안 작성
- 결재 상태 흐름
- 승인/반려/회수
- 완료 기준: 결재 흐름이 정상적으로 전환된다.

## 6. 게시판 모듈
- 공지사항/자유게시판 목록
- 글 작성/수정/삭제
- 댓글 기능
- 완료 기준: 게시글과 댓글이 저장 및 조회된다.

## 7. 관리자 모듈
- 사원 관리
- 프로젝트 관리
- 권한 관리
- 완료 기준: 관리자가 기본 운영 업무를 수행할 수 있다.
