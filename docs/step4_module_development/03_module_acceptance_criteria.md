# 4단계 산출물: 모듈별 완료 기준

## 1. 인증 모듈 완료 기준
- SSO 로그인으로 진입 가능하다.
- 화이트리스트에 등록된 계정만 접근 가능하다.
- 세션 유지와 로그아웃이 동작한다.

## 2. 대시보드 완료 기준
- 로그인 후 대시보드가 정상 표시된다.
- 근태, 결재, 공지사항 요약이 확인된다.

## 3. 타임시트 완료 기준
- 프로젝트와 날짜를 선택해 시간을 입력할 수 있다.
- 하루/월간 제한 로직이 동작한다.
- 저장과 마감이 가능하다.

## 4. 근태 완료 기준
- 출근/퇴근 버튼이 동작한다.
- 근태 기록이 저장되고 조회된다.

## 5. 전자결재 완료 기준
- 기안 작성이 가능하다.
- 결재 상태가 전환된다.
- 승인/반려/회수 버튼으로 흐름이 동작한다.

## 6. 게시판 완료 기준
- 글 작성과 조회가 가능하다.
- 댓글 기능이 동작한다.
- 관리자 권한에 따라 공지사항 작성이 가능하다.

## 7. 관리자 완료 기준
- 사원, 프로젝트, 권한 정보를 관리할 수 있다.
- 권한에 따라 접근이 분기된다.
